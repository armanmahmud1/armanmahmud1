Statistician and data scientist working at the intersection of **public health**, **machine learning**, and **impactful research**. I build open-source tools that take the grunt work out of survey workflows, from XLSForm to clean dataset to print-ready questionnaire.

Currently building with **agentic AI** (Claude Code, Gemini) for research automation, code generation, and small AI-powered apps.

## Recently Shipped

- 📄 **[XLSForm2Word v1.2.2](https://github.com/armanmahmud1/XLSForm2Word)**: Windows app that turns ODK, SurveyCTO, and KoboToolbox XLSForms into print-ready Word questionnaires. One document per language, right-to-left support (Arabic, Urdu), no install or internet needed.

## Open-Source Packages

> Stata & R packages built to simplify survey workflows and statistical analysis.

| Package | Lang | Description |
|:--------|:----:|:------------|
| [`odkrepeatmerge`](https://github.com/armanmahmud1/odkrepeatmerge) | Stata | Merge ODK repeat groups (any nesting depth) into one wide dataset, in questionnaire order |
| [`surveyprint`](https://github.com/armanmahmud1/surveyprint) | Stata | Lay out an ODK questionnaire in Excel (English & Bangla) for printing or PDF |
| [`sendemail`](https://github.com/armanmahmud1/sendemail) | Stata | Send emails directly from Stata |
| [`sctofiles`](https://github.com/armanmahmud1/sctofiles) | Stata | Preserve renamed media files collected during surveys |
| [`basicstat`](https://github.com/armanmahmud1/basicstat) | Stata | Basic statistics for both string and numeric variables |
| [`do-template`](https://github.com/armanmahmud1/do-template) | Stata | Generate a do-file template with author info and formatting |
| [`autochart`](https://github.com/armanmahmud1/autochart) | R | Auto-generate charts based on variable data types |

**Install any Stata package** (swap in the package name):

```stata
net install odkrepeatmerge, from("https://raw.githubusercontent.com/armanmahmud1/odkrepeatmerge/main/") replace
```
